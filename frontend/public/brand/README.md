# Adey logo: usage

**Idea:** the Adey Abeba flower, whose seed is a speech bubble — the answer at the heart of the flower.

## Files
| File | Use |
|---|---|
| `adey-mark.svg` / `.png` | Primary mark, full colour, on light backgrounds |
| `adey-mark-black.svg` | One colour, print/stamps/embroidery |
| `adey-mark-white.svg` | One colour reversed, on dark or photo backgrounds |
| `adey-mark-mono-f2c230.svg` | All petal yellow, on highland green / dark |
| `adey-mark-mono-1e4d3a.svg` | All highland green, on light/cream |
| `adey-mark-mono-3a2614.svg` | All seed brown, on yellow backgrounds (e.g. the home-page hero) |
| `adey-lockup-horizontal.svg` / `-512h.png` | **Primary logo**: mark + "Adey", on white/light |
| `adey-lockup-horizontal-on-yellow.svg` | Brown mark + ink name, on yellow backgrounds |
| `adey-lockup-horizontal-reversed.svg` | Yellow petals, Seed-brown bubble + cream name, on highland green/dark |
| `adey-lockup-horizontal-black.svg` | One colour |
| `adey-lockup-stacked*.svg` / `-1024h.png` | Same four versions, stacked, for square spaces |
| `adey-wordmark.svg` | Name only, for places where the mark already appears |
| `adey-mark-app-icon.svg`, `icon-*.png`, `apple-touch-icon.png`, `maskable-512.png` | App and PWA icons (yellow on highland green) |
| `favicon.ico`, `favicon.svg`, `favicon-*.png`, `site.webmanifest`, `head-snippet.html` | Browser icons |

## Colour
| Name | HEX | RGB |
|---|---|---|
| Petal | `#F2C230` | 242 194 48 |
| Seed | `#3A2614` | 58 38 20 |
| Highland (tiles, reversed backgrounds) | `#1E4D3A` | 30 77 58 |

Never put the full-colour mark on brown or green: the seed disappears. Use `mono-f2c230` or `white` there instead.
Never put the full-colour mark on yellow: the petals disappear. Use `mono-3a2614` / `-on-yellow` there instead.

## Clear space and minimum size
- Clear space on every side: the seed bubble's diameter (about 27 % of the mark's width).
- Minimum size: 24 px on screen, 10 mm in print. Below that, the bubble's tail is lost and the mark reads as a plain flower.

## Don't
Stretch it, rotate it, recolour individual petals, add shadows or gradients, close the gap between the bubble and the petals, or place the yellow mark on white at very small sizes.

## Wordmark
"Adey" is Schibsted Grotesk SemiBold (600), tracking +1.2 %, colour `#15192C`, converted to outlines (font: SIL Open Font License).
- Horizontal: cap height = 41 % of the mark's height; the cap band is centred on the mark; gap between mark and name ≈ the seed bubble's diameter.
- Stacked: cap height = 28 % of the mark's height, centred under the mark.
Always use the lockup files; don't retype the name next to the mark.
